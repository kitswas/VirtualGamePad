Virtual GamePad is a small ecosystem of five repositories maintained by one person. After several months with little activity, this weekend was a deliberate attempt to take stock, reduce the fear of touching things, and make the projects easier to work on.

## The ecosystem

- **VirtualGamePad**: documentation website (Hugo).
- **VirtualGamePad-PC**: Qt desktop server that turns network input into a virtual gamepad.
- **VirtualGamePad-Mobile**: Android client.
- **VGP_Data_Exchange**: the shared wire protocol.
- **VGP-builds**: build and packaging experiments.

## Where things stood

On October 15 I checked all five repositories.

- The docs and PC repositories were up to date.
- Mobile had 7 local commits that had never been pushed. They included a Gradle, Kotlin and library upgrade and had been sitting locally for about two months.
- `VGP_Data_Exchange` and `VGP-builds` had not changed since April.
- Mobile had 4 open pull requests and 11 open issues. PC had 1 open pull request and 8 open issues.

The main obstacles were not code. Setting up both Android and Qt toolchains takes a long time, nothing was automated, and every change was tested by hand with a real game. That makes every change feel risky.

## What changed this week

### Process and organization

- Added pull request templates to PC and Mobile.
- Added [`mise`](https://mise.jdx.dev/) as a task runner, so common commands are documented and runnable in one step.
- Website got a blog section which serves this post you are reading. ;)

### Mobile

- Reviewed, tested and merged PR #33 (keep screen on).
- Added ktlint for Kotlin style enforcement.
- Switched the `VGP_Data_Exchange` submodule URL to HTTPS.
- Updated GitHub Actions, the emulator-runner action and the supported API levels.

### PC

- Unified deployment script generation.
- Added installable (non-portable) presets and build tasks for Windows and Linux.
- Portable builds now fail loudly if their folder is not writable.
- Improved the uinput accessibility check and the Linux permission instructions.
- I tested on Fedora KDE Plasma and Windows 11.
